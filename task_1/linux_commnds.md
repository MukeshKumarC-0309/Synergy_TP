# Linux Commands — Task 1

## pwd
**Command:** `pwd`  
**What it does:** Prints the current working directory  


## ls
**Command:** `ls`  
**What it does:** Lists files in the current directory  


## ls -la
**Command:** `ls -la`  
**What it does:** Lists all files including hidden ones, with permissions and sizes  

## mkdir
**Command:** `mkdir ...`
**What it does:** It creates a new folder/directory from the current working directory

## touch
**Command:** `touch`
**What it does:** It creates a new file whose extension is predetermined by the user

## cd
**Command:** `cd ...`
**What it does:** It changes the present working directory to that of the one presented in the arguement
